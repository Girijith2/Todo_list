📝 Todo List Web App

A simple and responsive **Todo List Web Application** built using  
**HTML, CSS, and JavaScript** to manage daily tasks easily.

---

🚀 Features

- ➕ Add new tasks
- ✅ Mark tasks as completed
- 🗑️ Delete tasks
- 📱 Responsive design for mobile & desktop
- ⚡ Fast and lightweight UI

---

🛠️ Technologies Used

- HTML5  
- CSS3  
- JavaScript (Vanilla JS)
